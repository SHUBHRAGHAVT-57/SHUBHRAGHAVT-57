# Shubh Raghav

I build interactive web apps with React and TypeScript and native Android apps with Kotlin. Lately I’ve been working on how apps handle real interruptions, like picking up a study session after a refresh or keeping edits when a connection drops.

## Selected projects

### [KeyTurn](https://github.com/SHUBHRAGHAVT-57/bookdesign)

An interactive study book that pairs reading with typing and recall. When you mistype a word or pause on it, KeyTurn can bring that word back in a short review. Progress stays in your browser, and the app works offline after the first visit.

**[Try KeyTurn](https://bookdesign-wine.vercel.app)** · [How the review picks words](https://github.com/SHUBHRAGHAVT-57/bookdesign#how-echo-review-picks-a-word)

<a href="https://bookdesign-wine.vercel.app"><img src="assets/keyturn.webp" width="650" alt="KeyTurn’s two-page study book with reading passages, typing fields, and live feedback."></a>

### [Lensqivo](https://github.com/SHUBHRAGHAVT-57/Lensqivo)

An Android camera built with Kotlin, Jetpack Compose, and CameraX. A shared shader applies the same color treatment to preview and export, and the app preserves the original photo if an edit fails. Physical-camera testing is pending. [Validation record](https://github.com/SHUBHRAGHAVT-57/Lensqivo/blob/main/docs/validation.md)

### [SyncVerse](https://github.com/SHUBHRAGHAVT-57/syncverse)

A shared Markdown editor with live cursors and offline editing. IndexedDB keeps edits in the browser and Yjs merges concurrent changes. The prototype runs with a local relay. [Architecture](https://github.com/SHUBHRAGHAVT-57/syncverse/blob/main/docs/ARCHITECTURE.md)

### [For You](https://github.com/SHUBHRAGHAVT-57/Gift-for-Soemeone)

A TypeScript and Three.js experiment that turns a personal note into a shareable particle rose or ring. The reveal has a still mode for reduced-motion settings. [Open the demo](https://shubhraghavt-57.github.io/Gift-for-Soemeone/)

### [Algorithmic Lab](https://github.com/SHUBHRAGHAVT-57/algorithmic-lab)

Four Python implementations with complexity notes and edge-case tests, covering hash maps, maximum subarrays, binary search, and breadth-first search.
