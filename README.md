## Featured work

### [KeyTurn · Personal Memory Edition](https://github.com/SHUBHRAGHAVT-57/bookdesign)

Type a passage into a two-page book, then answer a recall question. KeyTurn uses corrections and long pauses to choose words for a later fill-in-the-blank review. Close the tab and your place is saved in the browser.

<p align="center"><a href="https://bookdesign-wine.vercel.app">
  <img src="assets/keyturn.webp" width="720" alt="KeyTurn’s two-page book showing a study passage, typing input, and live feedback.">
</a></p>

**[Open the study book](https://bookdesign-wine.vercel.app)** · [How word review works](https://github.com/SHUBHRAGHAVT-57/bookdesign#how-echo-review-picks-a-word)

### [Lensqivo](https://github.com/SHUBHRAGHAVT-57/Lensqivo)

A native Android camera with eight live color looks. You can dial in the strength of a look or compare it with the original before shooting. If a full-resolution edit fails, the app saves the original photo.
